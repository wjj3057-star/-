# 오늘출석 1.4.2 추가 검토

완료일: 2026-10-15. 버전: `1.4.2` / `versionCode 12`.

## 재현 및 수정

### 학부모 번호 변경 중 수신 체크가 옛 번호에 적용됨

기존 학부모 번호를 다른 번호로 수정한 뒤 수신 체크를 바꾸면, 아직 화면에만 입력된 새 번호 대신 저장된 옛 번호의 수신 설정이 즉시 바뀌었다. 학생 정보 저장이 실패하거나 편집을 취소해도 이 변경은 남았다.

입력된 번호와 저장된 번호를 정규화해 비교하도록 수정했다. 번호가 다르면 수신 설정도 입력 중인 값으로 유지하고 `변경 저장`으로 번호와 함께 적용한다. 저장 실패 시 기존 연락처·수신 설정과 작성 중인 입력을 보존하여 재시도할 수 있다. 화면에 이 저장 방식을 안내한다.

번호가 같으면 수신 체크의 즉시 저장을 유지한다. 하이픈·공백·`+82` 형식만 달라진 같은 번호도 자동 저장되며, 작성 중인 학생 이름 등 다른 필드는 함께 저장하지 않는다.

### 늦게 도착한 백업 결과가 입력창을 없앰

백업 읽기가 완료되기 전에 학생 정보 창에서 내용을 작성하면, 읽기 완료 콜백이 복원 확인창으로 화면을 교체하면서 작성 중인 내용이 사라졌다.

다른 창이 열려 있으면 유효한 백업 데이터를 대기시키고 현재 창을 유지한다. 사용자가 현재 작업을 저장하거나 창을 닫으면 복원 확인창을 표시한다. 닫기 동작이 다른 창을 여는 경우에는 그 창도 덮어쓰지 않는다. 복원 동의 전에는 데이터를 변경하지 않으며, 취소·저장 실패 시 기존 데이터를 유지한다. 복원 후 문자 자동 발송이 꺼지는 기존 동작도 유지한다.

두 문제 모두 수정 전 테스트에서 재현했다. 실제 주소록을 조회하거나 문자를 보내지 않았다.
