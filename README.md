# 오늘출석 · Academy Attendance

학원 선생님이 **반 구분 없이 전체 학생의 출석을 관리**하고, 학부모에게 출석 SMS를 보낼 수 있는 Android 앱입니다.

- 버전: **1.4.0** (`versionCode 10`)
- 한국어 UI, Android 8.0 (API 26) 이상
- 기기 내부 저장 방식으로 인터넷, 계정, 외부 서버 불필요

## 1.4.0 출석 중심 화면 개편

- 앱을 열면 한 줄 주간 달력, 학생 검색창과 출석 버튼이 바로 표시됩니다. 전체 현황과 출석률 카드는 **기록·통계** 탭으로 옮겼습니다.
- 출석부 검색창은 스크롤 중에도 상단에 유지됩니다. 이름 일부, 초성(예: `ㄱㅎ`), 띄어쓰기를 무시한 이름으로 검색하고 지우기 버튼으로 전체 목록에 돌아갈 수 있습니다. 학생 관리에서도 같은 검색을 제공합니다.
- 학생은 기본 가나다순으로 표시합니다. 검색 결과 수와 정렬 기준을 안내하며, 기존 페이지 분할과 검색 결과 전체에 대한 일괄 출석은 유지합니다.
- 학생 카드와 출석 버튼의 간격·대비를 조정했습니다. 출석 버튼은 높이 46px이며 선택한 상태는 색상·테두리·체크 표시로 구분합니다. 넓은 화면에서는 학생 목록을 두 열로 보여 줍니다.
- **기록·통계 → 일별 출석 현황**에서 날짜별 등원 인원, 출결 상태, 출석률을 볼 수 있습니다. `출석부 보기`로 해당 날짜의 체크 화면에 돌아갑니다. 일별 출석률은 월간 기록과 같은 공식으로 계산하며 체크 완료 인원과 따로 표시합니다.

검증 결과와 설치 안내: [1.4.0 개편 기록](docs/REVIEW-1.4.0.md).

## 1.3.3 반복 검토 수정 사항

- 문자 결과 대기 시간은 발송 준비가 끝난 뒤 통신망 요청 직전부터 계산합니다. 앱 실행 중 휴대폰 시간을 앞뒤로 바꿔도 재전송 버튼이 너무 일찍 나타나거나 대기가 길어지지 않도록 경과 시간을 사용합니다. 지연 성공 응답도 계속 반영합니다.
- 문자 발송 기록을 저장하는 동안에도 자동 발송 끄기 설정을 반영할 수 있습니다. 기록 저장을 마친 뒤 최신 설정을 다시 확인하여 통신망에 전달하기 전의 발송을 취소합니다.
- 출석부·학생 목록·학생별 월간 기록을 50명씩 표시합니다. 검색은 전체 학생을 대상으로 하며 일괄 출석도 다른 페이지를 포함한 검색 결과의 미출석 학생 전체에 적용합니다. 실행 전 확인창에서 범위를 안내합니다.
- 학생의 과거 기록을 누르면 그 날짜에서 해당 학생이 있는 페이지로 이동하고 초점을 맞춥니다. 날짜·검색 조건을 바꾸면 첫 페이지부터 표시합니다.
- 백업 파일을 읽거나 쓰는 도중 화면이 재생성되어도 완료 결과를 새 화면에 전달합니다. 재생성 대기 중 결과와 새 화면의 준비 상태를 분리하며, 앱을 정상 종료하면 남은 화면 알림을 정리합니다.
- 최대 5,000명 화면, 페이지 밖 일괄 출석과 되돌리기, 4,000회 연속 출결 변경과 백업 왕복을 회귀 검증에 추가했습니다.

반복 검토와 검증 결과: [1.3.3 검토 기록](docs/REVIEW-1.3.3.md).

## 1.3.2 추가 정밀 검토 수정 사항

- 확인된 SMS 성공 결과가 모순되는 중복 콜백 때문에 실패로 바뀌지 않습니다. 재전송 준비 중 이전 문자의 성공 응답이 도착하면 통신망에 넘기기 직전에 다시 확인하고 재전송을 취소합니다.
- 저장 완료를 알리기 전에 파일 동기화와 실제 저장 내용을 확인합니다. 저장 API가 오류를 던지지 않고 파일 교체에 실패하는 경우도 감지하며, 문자 발송 기록을 저장하지 못했을 때는 통신망 발송을 시작하지 않습니다.
- 연락처 재조회 중 이전 주소록 목록을 선택할 수 없도록 했습니다. 조회 오류 상태에서 검색해도 재시도 안내가 유지됩니다.
- 자동 등록 후보를 20명씩 표시하고 기존 학생을 검색해 연결할 수 있습니다. 페이지를 바꿔도 이름·연락처 선택·체크는 유지되며, 전체 선택·해제와 선택 인원 안내를 추가했습니다. 검색창의 Enter 키로 등록이 실행되지 않습니다.
- 파일 선택 중 Android가 화면을 다시 생성해도 내보낼 백업 내용을 임시 파일로 유지합니다. 복원 결과가 화면 준비보다 먼저 도착하면 준비가 끝난 뒤 전달합니다. 완료·취소된 내보내기 임시 파일은 삭제합니다.
- 학생·기록 수 한도와 문자 기록 저장 오류를 구체적인 한국어 안내로 표시합니다.

검토 범위와 재현·검증 내용: [정밀 검토 기록](docs/REVIEW-1.3.2.md).

## 1.3.1 전체 검토 수정 사항

- 화면이 다시 생성돼도 하나의 저장소에서 설정·문자 사용 동의를 확인합니다. 자동 발송을 껐다 켜도 이전 대기 요청은 취소하며, 잘못된 설정은 기존 데이터를 덮어쓰기 전에 거절합니다. 저장 실패 시 기존 데이터와 설정을 유지합니다.
- 문자 재전송 순서를 휴대폰 시계 변경과 무관하게 판별합니다. 이전 시도의 성공 결과가 늦게 도착하면 추가 재전송을 차단하고, 재전송이 끝난 옛 기록에는 다시 보내기 버튼 대신 최신 결과 안내를 표시합니다.
- SIM·문자 분할 등 발송 준비 단계의 오류가 일괄 발송을 중단하거나 결과 대기로 남지 않도록 처리합니다. 통신망에 전달한 뒤 발생한 오류는 계속 결과 미확인으로 표시합니다. 연락처 번호에 들어간 특수 공백도 화면과 Android에서 동일하게 처리합니다.
- 연락처 선택에 **더 보기**를 추가해 100개 이후 번호도 선택할 수 있습니다. 권한이 허용된 상태에서 연락처를 읽지 못해도 **다시 불러오기**로 재시도하며, 입력 중인 학생 정보는 유지합니다.
- 날짜·조회 월 입력을 비우면 기존 선택을 복구해 화면과 실제 저장 날짜가 달라지는 문제를 방지합니다. 결석·공결 표기, 연락처 키워드 입력 길이, 데이터 재조회 시 보관 학생 표시도 수정했습니다.

## 1.3.0 수정 사항

- **화면 테마**에서 기기 설정 / 라이트 / 다크를 선택하면 즉시 저장합니다. 기본값은 기기 설정이며 앱을 켠 채로 기기 테마를 바꾸거나 돌아왔을 때도 반영됩니다. 입력 중인 양식은 유지하고 상태바·내비게이션바 색상도 맞춥니다.
- **자동 발송·발송 대상 출결·기존 학부모 수신 여부·보관 학생 표시** 체크를 즉시 저장합니다. 저장 실패 시 체크를 되돌리고 오류를 표시합니다. 발송 대상을 모두 해제하면 자동 발송도 끕니다. 문자 문구와 새 학생·연락처 정보는 작성 후 저장합니다. 연락처 등록 후보 선택과 백업 교체 확인은 실행 전 선택이므로 등록·복원 버튼으로 완료합니다.
- 실제 성공 결과를 실패로 기록하던 수신기 수정(1.2.2)을 포함합니다. 분할 문자 전체 결과가 도착하기 전에는 결과 대기를 유지하고, 일부 성공·실패를 구분해 표시합니다. 지연 성공 응답이 도착하면 미확인 상태도 갱신합니다. 구버전에서 잃어버린 결과는 결과 미확인으로 표시하며 임의로 성공 처리하거나 자동 재전송하지 않습니다.
- 권한 취소 등으로 재전송 요청 자체가 실패하면 요청 완료 안내가 뜨지 않습니다. 발송 기록은 화면 복귀 시 즉시 갱신하고, 내용이 같을 때는 스크롤·선택·초점을 유지합니다.

## 1.2.2 수정 사항

- 자동 발송 스위치의 켜짐·꺼짐을 즉시 저장합니다. 닫기·뒤로가기·재실행 후에도 유지하며, 저장 실패 시 기존 상태로 돌리고 오류를 표시합니다. 문구·발송 대상은 문자 설정 저장 버튼으로 적용합니다.
- Android 문자 결과 코드를 `goAsync()` 호출 전에 읽도록 수정했습니다. 실제 성공을 실패 코드 0으로 기록하던 오류를 해결하고, 이전 버전의 잘못된 결과는 성공·실패를 단정하지 않고 결과 미확인으로 표시합니다.
- 각 문자 요청 직전에 최신 자동 발송 설정·출결·수신 동의를 확인합니다. 일괄 발송 도중 끄면 남은 요청을 취소하며, 다시 켜도 취소된 요청을 소급 발송하지 않습니다. 이미 통신사로 전달한 문자는 취소할 수 없습니다.
- 백업 JSON의 불필요한 들여쓰기를 없앴습니다. 내부 저장 한도 24MiB보다 파일 입출력 한도를 25MiB로 크게 두어, 저장 가능한 데이터는 백업 정보까지 포함해 내보내고 복원할 수 있습니다. 한글은 UTF-8 바이트 기준으로 크기를 검사합니다.
- 연락처 검색 중 다른 창으로 이동하면 이전 검색 결과가 입력 중인 창을 덮어쓰지 않습니다. 구형 WebView에도 긴 설정창의 높이 제한을 적용합니다.

## 1.2.1 수정 사항

- 문자 권한이나 기본 SIM 설정 전에도 문구·발송 대상·자동 발송 사용 여부를 저장합니다. 실제 발송은 기기·권한·SIM이 준비된 뒤 새로 체크하는 출결부터 요청합니다. 준비되지 않은 동안의 출결을 나중에 자동 소급 발송하지 않습니다.
- 문자 권한이 확인되면 권한 요청·앱 권한 설정 버튼을 숨깁니다. 시스템 설정에서 돌아오거나 권한이 취소되면 표시를 갱신하며, 작성 중인 문구는 유지합니다.
- 연락처 권한을 허용하고 돌아오면 진행 중이던 연락처 선택·검색을 다시 불러옵니다.
- 저장 실패 시 입력값을 유지하고 양식 안에 오류를 표시하여 재시도할 수 있습니다. 자동 발송을 끈 상태에서는 발송 대상 선택을 모두 해제해도 저장할 수 있습니다.
- 이전 버전의 최대 반 개수(200개)를 가진 데이터도 새 내부 호환 항목을 포함해 정상 저장합니다.
- 자정에 출석 메모·일괄 체크·기록 삭제 확인창은 종료하고, 설정·학생 등록에서 입력 중인 내용은 유지합니다. 지난 날짜의 확인 버튼이 다음 날짜에 출석을 변경하지 않도록 보호합니다.

## 출석 체크 및 자정 초기화

1. **학생 관리 → 학생 등록**에서 학생 이름과 등록일을 입력합니다. 반 생성 또는 반 선택 과정은 없습니다.
2. **출석 체크**에서 학생별로 **출석 / 지각 / 결석 / 공결** 중 하나를 선택합니다. 선택한 상태를 한 번 더 누르면 **미출석**으로 변경됩니다.
3. **미출석 모두 출석** 버튼은 다른 페이지를 포함한 현재 검색 결과의 미출석 학생 전체를 일괄 출석 처리합니다.
4. 매일 **기기 현지 시간 오전 0시**에 화면이 새 날짜로 전환되며, 활성 학생 전체가 **미출석** 상태로 시작합니다.
5. **어제의 출석 기록은 삭제되지 않습니다.** 날짜 선택, 출석 기록 화면, CSV로 과거 기록을 조회할 수 있습니다.

앱을 켜 둔 상태에서는 다음 자정 시각에 맞춘 타이머로 화면을 전환합니다. 앱이 백그라운드에 있거나 종료된 경우에도 다음에 화면으로 돌아올 때 날짜를 다시 확인하고 새로운 출석부를 표시합니다. Android 절전 정책으로 백그라운드 타이머가 지연될 수 있지만, 날짜별 출결은 독립적으로 보관되기 때문에 과거 상태가 새 날짜에 복사되지 않습니다. 보관 중인 학생은 새로운 출석부에 나타나지 않습니다.

**기존 데이터:** 버전 1.0/1.1에서 저장된 학생·학부모 정보와 과거 출결은 유지합니다. 과거 반 구분은 새로운 화면에서 사용하지 않으며, 구버전 기록과 백업을 읽을 수 있도록 내부 호환성 정보만 보존합니다. 새로 추가한 학생은 반을 선택하지 않습니다.

## 연락처 연동

**학생 관리 → 연락처에서 자동 등록**에서 휴대폰 주소록을 읽어 학생과 학부모 전화번호를 연결할 수 있습니다.

- `김하늘 어머니`, `김하늘아버지`, `(김하늘)어머니`, `김하늘(어머니)`, `김하늘 학생` 같은 이름을 인식합니다.
- 키워드는 설정에서 편집할 수 있으며 동명이인은 사용자가 연결할 기존 학생을 직접 선택합니다.
- 학생 연락처와 최대 6개의 학부모 연락처를 저장합니다.
- 주소록은 요청할 때만 읽습니다. 기존 연락처는 수정하지 않으며, 자동 등록만으로 문자를 발송하지 않습니다.
- 자동 등록 후보는 20명씩 확인합니다. 다른 페이지의 선택도 함께 등록되며, 전체 선택·해제와 선택 인원으로 범위를 확인할 수 있습니다. 기존 학생 검색은 이름·전화번호·목록 번호(예: `12번`)를 지원합니다.

## 학부모 문자 발송

**설정 → 출석 문자 설정**에서 문자 발송 권한을 허용하고 자동 발송을 활성화할 수 있습니다. 자동 발송 스위치와 발송 대상 체크는 즉시 저장되며 문구 편집은 **문구 저장**으로 적용합니다. 발송 대상을 모두 지운 상태라면 대상을 선택한 뒤 스위치를 켜 주세요.

- 기본적으로 오늘 날짜의 **출석 및 지각 상태 변경** 시 수신 동의가 설정된 학부모 번호로 SMS를 요청합니다.
- 문자 문구와 발송 대상 상태는 수정할 수 있습니다. 기본 문구는 아래와 같습니다.
- 메모만 변경하거나 미출석으로 되돌릴 때, 과거 기록을 수정할 때, 백업을 복원할 때는 자동 문자 발송을 요청하지 않습니다.
- 같은 학생·날짜·상태·정규화된 전화번호 조합으로 자동 중복 발송을 하지 않습니다.
- **설정 → 문자 발송 기록**에서 최근 200건의 처리 상태를 확인합니다.
- 기본 SMS용 SIM과 `SEND_SMS` 권한이 필요하며, 통신사 요금제에 따라 추가 문자 요금이 발생할 수 있습니다.

```text
[{학원명}] {학생이름} 학생이 {날짜} {시간}에 {상태} 처리되었습니다.
```

문자 치환 항목: `{학원명}`, `{학생이름}`, `{날짜}`, `{시간}`, `{상태}`, `{선생님}`, `{메모}`.
기존 버전에서 저장한 `{반이름}` 템플릿은 백업 호환성을 위해 해석할 수 있으나, 신규 편집 화면에서는 권장하지 않습니다.

**문자 발송 완료**는 통신망 발송 결과이며 학부모의 실제 수신 또는 읽음을 보증하지 않습니다. 문자가 실패했거나 응답이 불확실할 때 자동 재전송하지 않습니다. 문자를 보낸 뒤 출결을 되돌려도 이미 전송된 문자는 취소할 수 없습니다.

## 출석 기록 및 데이터 관리

- 월별 출석률 = (출석 + 지각) / (출석 + 지각 + 결석)
- 공결과 미출석은 출석률 계산에서 제외합니다.
- 등록일부터 출석부에 표시되며, 보관된 학생의 과거 기록은 유지합니다.
- **설정 → 전체 데이터 백업**: JSON 파일 저장
- **설정 → 백업 파일 복원**: 유효성을 검사하고 동의를 받은 뒤 현재 데이터를 교체합니다. 복원 후 문자 자동 발송 설정은 꺼집니다.
- **출석 기록 → CSV 내보내기**: 현재 월별 기록을 파일로 내보냅니다.

학생 이름과 전화번호가 포함된 JSON 백업은 **암호화되어 있지 않습니다.** 공유하거나 보관할 때 주의하세요. 문자 발송 기록은 JSON 백업에 포함되지 않습니다.

WebView에는 번들 로컬 자산만 로드합니다. 외부 페이지 탐색은 차단하고, HTML 문자열은 이스케이프합니다. 출석 데이터는 앱 전용 디렉터리에 `AtomicFile`로 저장됩니다. 런타임 외부 라이브러리는 없습니다.

## APK 빌드 (PowerShell)

필요 도구: **JDK 17, Python 3.10 이상, Android SDK Platform 35, Build Tools 35.0.0**.

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
python .\scripts\build_apk.py
```

APK 출력: `out\AcademyAttendance.apk`

Android Studio를 사용할 경우 Gradle 8.9 / Android Gradle Plugin 8.7.3으로 빌드할 수 있습니다.

**배포 서명:** 채팅에서 제공한 1.4.0 APK는 1.3.3과 같은 서명입니다. 1.2.0 APK와는 서명이 달라 덮어쓰기 업데이트할 수 없습니다. 1.2.0을 사용하는 경우 기존 앱의 설정에서 JSON 전체 백업을 저장한 뒤 설치·복원해야 합니다. 백업 전에는 기존 앱을 삭제하지 마세요.

**업데이트 주의:** 기기에 설치된 기존 앱의 데이터를 유지하려면 이전 APK와 **동일한 서명 키**를 사용해야 합니다. 신규 설치용 임시 키와 기존 배포 키는 서로 교환할 수 없습니다. GitHub Actions의 테스트 APK는 실행마다 새 임시 키로 서명되므로 기존 설치본 업데이트용으로 사용하지 마세요. 원래 APK의 서명 키를 보관한 상태에서 `--keystore` 옵션으로 재사용하세요.

```powershell
python .\scripts\build_apk.py --keystore "C:\MyPrivateKeys\AcademyAttendance-signing.keystore"
```

```powershell
node --test .\tests\core.test.cjs .\tests\contacts-sms.test.cjs
node --check .\app\src\main\assets\core.js
node --check .\app\src\main\assets\app.js
node --check .\app\src\main\assets\contacts-sms.js
java -m jdk.compiler/com.sun.tools.javac.Main -encoding UTF-8 -d out\sms-tests .\app\src\main\java\kr\academy\attendance\SmsRules.java .\tests\SmsRulesTest.java
java -cp out\sms-tests SmsRulesTest
```

선택적 UI 테스트:

```powershell
npm install --no-save playwright
npx playwright install chromium
node .\tests\ui.cjs
node .\tests\contacts-ui.cjs
node .\tests\settings-ui.cjs
node .\tests\midnight-ui.cjs
node .\tests\theme-autosave-ui.cjs
node .\tests\audit-ui.cjs
node .\tests\deep-audit-ui.cjs
node .\tests\scale-ui.cjs
node .\tests\attendance-layout-ui.cjs
```

네이티브 회귀 테스트는 JDK 17과 테스트 전용 org.json 20240303 JAR를 사용합니다. CI는 의존성을 내려받은 뒤 `python tests/native_sms.py --json-jar <jar 경로>`로 실제 문자 수신기·발송 큐·저장소·파일 전달 코드를 모의 Android 환경에서 실행합니다. 실제 문자는 보내지 않습니다.

실제 Android 기기에서의 연락처 권한, 통신사 SMS 발송, 배터리 절전 상황은 별도 실기기 검증이 필요합니다.
