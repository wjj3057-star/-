# 오늘출석 1.4.0 화면 개편

완료일: 2026-10-14. 버전: `1.4.0` / `versionCode 10`.

## 화면과 사용 흐름

- 첫 화면의 출석률·전체 현황 카드를 `기록·통계` 탭으로 옮겼다. 앱 실행 직후에는 기존 한 줄 주간 달력과 날짜 선택, 검색, 학생별 출석 버튼이 표시된다.
- 출석부 검색창은 스크롤 중에도 위에 유지된다. 출석부와 학생 관리에서 이름 일부, 한글 초성, 공백을 무시한 이름을 검색할 수 있다. 예: `하늘`, `ㄱㅎ`, `김 하`.
- 기본 목록은 가나다순이다. 검색어를 지우면 전체 목록으로 돌아가며, 검색 조건이 바뀌면 첫 페이지부터 표시한다. 일괄 출석은 검색 결과 중 미출석 학생에만 적용하며 다른 페이지의 일치 학생도 포함한다.
- 학생 카드의 반복되는 시각 표시를 정리하고 상태 버튼 높이를 46px로 조정했다. 선택 상태를 색·체크 표시·테두리로 구분하며 넓은 화면은 두 열을 사용한다.
- 일별 통계에서 조회 날짜를 선택하고 해당 날짜 출석부로 돌아갈 수 있다. 일별 출석률도 `(출석 + 지각) / (출석 + 지각 + 결석)`으로 계산한다. 공결·미출석은 분모에서 제외하고 계산할 기록이 없으면 `—`로 표시한다. 체크 완료 인원은 별도로 표시해 출석률과 혼동하지 않게 했다.

화면 검증은 Chromium과 모의 Android 브리지를 사용했다. 실제 연락처를 읽거나 SMS를 보내지 않았다. Android 네이티브 코드는 이번 개편에서 변경하지 않았다. 물리 기기 및 통신사 망에서 직접 검증한 결과는 아니며, 원격 CI 성공을 의미하지 않는다.

채팅으로 제공한 **1.3.3과 같은 서명**이다. **1.2.0과는 서명이 다르므로 그 위에 업데이트 설치할 수 없다.** 1.2.0의 원래 개인 서명키는 현재 확보하지 못했다. 1.2.0 사용자는 기존 앱의 `설정 → 전체 데이터 백업`으로 JSON 파일을 확보한 뒤 새 앱 설치 및 복원을 진행해야 한다. 백업 전에는 기존 앱을 삭제하면 안 된다. 복원 시 문자 자동 발송은 꺼진 상태로 시작한다.

서명키는 저장소에 포함하지 않았다. 자동 CI의 임시 키 APK와 채팅의 배포 APK는 구분해야 한다.
